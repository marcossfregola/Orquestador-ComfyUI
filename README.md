# Orquestador ComfyUI

Aplicación de escritorio independiente para Windows orientada a ejecutar de forma durable y recuperable proyectos de video generativo por chunks secuenciales, usando ComfyUI como backend.

Para conocer el estado actual del proyecto, consultar [STATUS.md](STATUS.md), que es la autoridad única de estado vivo.

## Documentación autoridad

- [PROJECT.md](PROJECT.md) — visión, problema, alcance, no-alcance y primer release.
- [ARCHITECTURE.md](ARCHITECTURE.md) — fronteras, capas, responsabilidades y contratos conceptuales.
- [DATA_MODEL.md](DATA_MODEL.md) — semántica del dominio, estados, checkpoints y reconciliación.
- [COMFYUI_INTEGRATION.md](COMFYUI_INTEGRATION.md) — adaptador ComfyUI, Workflow Profiles, bindings y preguntas de verificación.
- [TESTING.md](TESTING.md) — estrategia de pruebas y evidencia.
- [ENVIRONMENT.md](ENVIRONMENT.md) — hechos verificados, antecedentes históricos y revalidaciones pendientes.
- [RULES.md](RULES.md) — reglas permanentes de desarrollo, seguridad y auditoría.
- [STATUS.md](STATUS.md) — autoridad única para el estado actual del proyecto.
- [ROADMAP.md](ROADMAP.md) — trabajo decidido de F0 a F10.
- [BACKLOG.md](BACKLOG.md) — ideas futuras no comprometidas.
- [DECISIONS.md](DECISIONS.md) — índice conciso de decisiones aprobadas.
- [PREPROJECT.md](PREPROJECT.md) — antecedente histórico preservado, no estado vivo.

Cada tema profundo tiene una única autoridad. Los demás documentos enlazan esa autoridad en lugar de duplicarla.
